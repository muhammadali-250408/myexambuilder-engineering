# Analysis

This section documents the analysis undertaken during the development and planning of MyExamBuilder.

The purpose of analysis was to understand the structure of exsisting papers in order to determine how to extract questions but also to determine the criteria that the generated papers should meet to resemble real papers.

The analysis covered:
- Paper data preperation
- Question structure
- Mark distribution
- Mark progression
- Variation between exam papers

The findings from the analysis were used to make better more informed system design decisions and more suitable algorithims
