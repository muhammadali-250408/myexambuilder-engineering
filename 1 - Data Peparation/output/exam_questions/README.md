# Exam question output
This is a snippet of what the code for data preparation does to past papers.

## Naming format
MARKS_YEAR_QUESITON NUMBER

### Year format
the first 2 character represent the paper's year so 20 means 2020.

If there is a 3rd character that represents what paper it was so 202 mean 2020 paper 2. Paper 1s do not have a 1 on the end

If there is a 4th character that represents the sitting it was so 202j means 2020 paper 2 june sititng.
