# Exam Question Output

This directory contains the output from the data preparation code. This is a snippet of what the code for data preparation does to past papers.

## Naming format

`MARKS_YEAR_QUESTION NUMBER`

### Year format

The first 2 characters represent the paper's year, so `20` means 2020.

If there is a 3rd character, that represents what paper it was. So `202` means the 2020 Paper 2. Paper 1s do not have a `1` on the end.

If there is a 4th character, that represents the sitting it was. So `202j` means the 2020 Paper 2 June sitting.
